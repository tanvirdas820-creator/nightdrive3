# Night Drive 3D

Open-world night driving game with multiplayer support.

## Features
- Free Roam & Multiplayer Race
- Room Chat
- Accounts (Register / Login)
- Cloud Save
- Owner Chat
- Ban & Kick system
- Zero dependencies

## How to Run

1. Node.js 18+ install karo
2. Game file ko `index.html` naam do
3. Server start karo:

```bash
node server.js
